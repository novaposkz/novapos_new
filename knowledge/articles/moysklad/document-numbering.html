Нумерация документов

Настройка сквозной и независимой нумерации документов, префиксов и правил уникальности.

Главная > База знаний > Нумерация документов

Нумерация ведется по порядку с самого первого документа или каждый год начинается с единицы. Настроить нумерацию можно в разделе Меню пользователя → Настройки → Настройки компании.

По умолчанию применяется сквозная нумерация для всех юрлиц компании. Чтобы настроить независимую нумерацию отдельно для каждого юрлица:

  1. Перейдите в раздел с документами, например Продажи → Заказы покупателей.
  2. Нажмите на шестеренку справа вверху.
  3. Поставьте флажок в строке Независимая нумерация документов для юрлиц.
  4. Нажмите на кнопку Сохранить.

Можно добавить для номеров префикс: например, INV для счетов. Задайте номер нового документа вручную: если предыдущий был 00010, укажите новый INV-00011. Следующий документ автоматически получит номер INV-00012.

При создании документа поле номера следует оставлять пустым — номер автоматически присваивается при сохранении.

Номер должен быть уникален. В зависимости от выбранных настроек он может быть уникален вообще, в рамках года, в рамках юрлица или в рамках года и юрлица.

Номера розничных документов уникальны в рамках точек продаж. Обновление нумерации каждый год в этом случае тоже работает.
